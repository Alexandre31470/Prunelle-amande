Prestations

Ces catégories et prestations alimentent à la fois la section « Prestations & tarifs » et le bon de commande du site. Chaque modification est enregistrée immédiatement — vos clientes la voient tout de suite.

Avantages

Les cartes affichées dans la section « Vos avantages » du site. Chaque modification est enregistrée immédiatement.

Clientes & réservations

Chaque bon de commande envoyé depuis le site apparaît ci-dessous. Ces informations sont privées : seule une personne connectée à cet espace peut les consulter.

Fiches clientes

Votre répertoire de clientes, indépendant des réservations — pour garder une fiche même sans bon de commande en cours. Depuis une réservation ci-dessus, utilisez « → Fiche cliente » pour la reprendre automatiquement ici.

Bons cadeaux

Chaque demande de bon cadeau envoyée depuis le site apparaît ci-dessous. Une fois le paiement réglé (terminal de paiement), confirmez-le ici : un code est généré et le bon cadeau est envoyé automatiquement par e-mail à la personne bénéficiaire.

Calendrier des rendez-vous

Un site statique ne peut pas enregistrer automatiquement les réservations dans une base de données. La solution la plus simple et gratuite est d'afficher ici votre Google Agenda.

  1. Ouvrez Google Agenda sur ordinateur, et créez (ou choisissez) l'agenda où vous notez vos rendez-vous.
  2. Dans les paramètres de cet agenda, ouvrez « Intégrer l'agenda ».
  3. Copiez le code affiché, et collez-le ci-dessous — l'adresse est automatiquement extraite.

Aperçu

Cet aperçu n'apparaît que dans cette page d'administration ; il n'est pas visible par vos clientes sur le site public, sauf si vous demandez de l'ajouter à une page dédiée.
